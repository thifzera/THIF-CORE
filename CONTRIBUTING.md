# Contribuindo

## Objetivo

Estabelecer um processo simples e profissional para contribuições no THIF CORE.

## Visão Geral

Qualquer contribuição é bem-vinda, desde correções de documentação até melhorias de arquitetura e módulos. O foco principal é manter o projeto organizado, claro e compatível com a visão do núcleo.

## Estrutura

### Como contribuir
1. Faça um fork ou clone do repositório.
2. Crie uma branch com um nome descritivo.
3. Realize alterações com foco em uma única responsabilidade.
4. Teste a alteração localmente, quando aplicável.
5. Abra um pull request com descrição objetiva.

### Padrões recomendados
- Manter o código e a documentação consistentes.
- Evitar mudanças que alterem funcionalidades sem necessidade.
- Escrever mensagens de commit claras.
- Documentar mudanças relevantes.

## Exemplos

```md
git checkout -b feature/nome-da-mudanca

git commit -m "docs: adicionar documentação inicial"
```
