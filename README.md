# THIF CORE

## Versão

THIF CORE v1.0.0-alpha.2

## Objetivo

Esta versão fornece uma experiência utilizável do núcleo, com inicialização, saudação natural, leitura de data/hora, clima, diagnóstico básico de CPU e memória, e encerramento em sequência.

## Requisitos

- Python 3.10+
- Dependências listadas em requirements.txt

## Como iniciar

1. Instale as dependências:
   - instalar_dependencias.bat
2. Inicie o projeto:
   - iniciar_thif_core.bat
3. Ou execute manualmente:
   - python main.py

## Configuração

Os valores de nome, cidade, voz e velocidade são lidos do arquivo config/config.json.

## Funcionalidades incluídas

- Som de inicialização
- Saudação natural
- Data e hora
- Clima e temperatura
- Diagnóstico de CPU e memória
- Despedida
