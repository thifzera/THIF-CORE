# Changelog

## Objetivo

Registrar de forma clara e profissional as mudanças relevantes do projeto THIF CORE, facilitando o acompanhamento de evolução, correções e entregas futuras.

## Visão Geral

Este documento funciona como o histórico de alterações do repositório. Ele deve ser atualizado sempre que houver uma mudança significativa em funcionalidades, arquitetura, módulos ou documentação.

## Estrutura

A estrutura recomendada para entradas é:

- Versão ou sprint
- Data da alteração
- Categoria da mudança: Adicionado, Alterado, Corrigido, Removido ou Documentado
- Resumo das mudanças

### Exemplo de registro

```md
## [0.1.0] - 2026-07-29

### Adicionado
- Documentação inicial do repositório.

### Documentado
- Estrutura do núcleo, módulos e fluxo de inicialização.
```
